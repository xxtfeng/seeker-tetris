# Seeker Tetris: Pro Edition 🎮

**Seeker Tetris** is a high-performance, mobile-optimized Tetris game specifically designed for the **Solana Seeker** mobile experience.

## 🚀 Features
* **Seeker Optimized**: Native full-screen immersive gameplay (PWA supported).
* **Play-to-Earn Mechanics**: Earn **TET COINS** based on your performance and line clears.
* **Web3 Integration**: Seamless Solana wallet connection for rewards and progress tracking.
* **Pro Edition UI**: Enhanced dark-mode interface with a custom loading experience.

## 🛠️ Mobile Experience
The game uses advanced meta-tags to ensure it runs like a native app on Seeker:
- Full-screen mode enabled.
- Custom splash screen with a smooth fade-out animation.
- High-definition pixel art assets.
